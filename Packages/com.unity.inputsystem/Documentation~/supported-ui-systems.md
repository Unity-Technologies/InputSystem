# Supported UI systems

Choose how the Input System works with Unity's UI stacks—UI Toolkit, uGUI, and IMGUI.

Compare compatibility by Unity version, add a [UI Input Module](using-ui-input-module.md) where required, or keep IMGUI on legacy input while the rest of your project uses the Input System.

| **Topic** | **Description** |
| :--- | :--- |
| **[Understand UI system compatibility](understand-ui-compatibility.md)** | See which UI stacks need the UI Input Module and how support varies by Unity version. |
| **[Using UI Input Module for UI support](using-ui-input-module.md)** | Add UI Input Module to your scene and wire Input System actions to uGUI or older UI Toolkit. |
| **[Use IMGUI alongside the Input System package](use-imgui-alongside-input-system.md)** | Use legacy Input Manager input for IMGUI while gameplay uses the Input System. |

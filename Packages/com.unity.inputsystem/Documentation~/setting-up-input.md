# Setting up input

Learn how to configure input to suit the needs of your project.

Before you can read input from users, you must configure how you want to recieve input. User input comes in many forms, from keyboard, mouse, gamepads, and more. The Input System allows you to configure the connection and meaning between controls on your user's physical input devices, and the way your game or app responds to those inputs.

Once you have set up input, you can then [respond to input](respond-to-input.md).

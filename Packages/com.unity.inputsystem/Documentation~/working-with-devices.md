# Working with devices

Observe and manage the set of connected Input Devices from script.

React when devices are added or removed at runtime, or create and destroy devices yourself—for example for tests, virtual input, or on-screen controls.

| **Topic** | **Description** |
| :--- | :--- |
| **[Monitor devices](monitor-devices.md)** | Subscribe to `InputSystem.onDeviceChange` to detect when devices are added or removed. |
| **[Manually add and remove devices](manually-add-remove-devices.md)** | Create or remove devices with `InputSystem.AddDevice()` and `InputSystem.RemoveDevice()`. |

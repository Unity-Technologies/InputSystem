# Supported sensors

Each sensor device implements a single control which represents the data read by the sensor. The following sensors are available:

| Sensor | Description | Android | iOS | WebGL |
| :---- | :---- | :---- | :---- | :---- |
| `Accelerometer` | Measures the acceleration of a device. | Yes | Yes | Yes |
| `Gyroscope` | Measures the angular velocity of a device. | Yes | Yes | Yes |
| `GravitySensor` | Determines the direction of the gravity vector relative to the device. | Yes | Yes | Yes |
| `AttitudeSensor` | Determine the orientation of a device. | Yes | Yes | Yes |
| `LinearAccelerationSensor` | Measures the acceleration of a device unaffected by gravity. | Yes | Yes | Yes |
| `MagneticFieldSensor` | Represents the magnetic field that affects the device. | Yes | No | No |
| `LightSensor` | Represents the ambient light measured by the device. | Yes | No | No |
| `PressureSensor` | Represents the atmospheric pressure measured by the device. | Yes | No | No |
| `ProximitySensor` | Measures how close the device is to the user. | Yes | No | No |
| `HumiditySensor` | Represents the ambient air humidity. | Yes | No | No |
| `AmbientTemperatureSensor` | Represents the ambient air temperature. | Yes | No | No |
| `StepCounter` | Represents the user's footstep count. | Yes | Yes | No |
| `HingeAngle` | Represents the hinge angle of foldable devices. | Yes | No | No |

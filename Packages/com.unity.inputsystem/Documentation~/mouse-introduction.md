# Mouse devices introduction

The Input System represents mouse input with the [Mouse](http://localhost:57437/com.unity.inputsystem@1.12/api/UnityEngine.InputSystem.Mouse.html) device layout that the [Mouse](http://localhost:57437/com.unity.inputsystem@1.12/api/UnityEngine.InputSystem.Mouse.html) class implements. 

Important: The Input System doesn't support the following:

* Input from multiple mice at the platform level.  
* Identifying the current display a mouse is on.

The Mouse class is based on the [Pointer](http://localhost:57437/com.unity.inputsystem@1.12/manual/pointers.html) layout so inherits its controls. It also implements additional controls outlined in the Mouse API documentation.

For a list of platforms that support mice, refer to \[Platform support\].

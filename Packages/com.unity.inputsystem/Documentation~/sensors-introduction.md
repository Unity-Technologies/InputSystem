# Sensors introduction

Sensors are [InputDevice instances](http://localhost:57437/com.unity.inputsystem@1.12/manual/Devices.html) that measure environmental characteristics of the device that the content is running on. Unity currently supports sensors on iOS and Android. Android supports a wider range of sensors than iOS.

For a list of platforms that support sensors, refer to \[Platform support\].

## Testing sensors

To test sensor input from your mobile device, use the [Unity Remote](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.12/manual/Debugging.html#unity-remote). Unity Remote supports [Accelerometer](http://localhost:57437/com.unity.inputsystem@1.12/manual/Sensors.html#accelerometer), [Gyroscope](http://localhost:57437/com.unity.inputsystem@1.12/manual/Sensors.html#gyroscope), [GravitySensor](http://localhost:57437/com.unity.inputsystem@1.12/manual/Sensors.html#gravitysensor), [AttitudeSensor](http://localhost:57437/com.unity.inputsystem@1.12/manual/Sensors.html#attitudesensor), and [LinearAccelerationSensor](http://localhost:57437/com.unity.inputsystem@1.12/manual/Sensors.html#linearaccelerationsensor).

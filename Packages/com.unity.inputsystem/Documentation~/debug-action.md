# Debug an action

The Input Debugger window lists all enabled [Actions](actions.md) in the __Actions__ list. This list only appears if at least one Action is active and the Editor is in Play mode. If an Action has actively bound Controls, you can click the arrow next to the Action to see a list of the Controls. This is useful to debug whether your bindings correctly map to the Controls you want them to bind to. Refer to [Binding resolution](binding-resolution.md) for more information about how Unity maps bindings to Controls.

> [!NOTE]
> Actions that belong to [`InputUsers`](user-management.md) don't appear here. They appear in the [__Users__](debug-users-playerinput.md) list instead.

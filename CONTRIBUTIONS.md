# Contributions

## We no longer accept external pull requests

The Input System is developed by Unity Technologies, and this repository is no longer open to pull requests from outside contributors. Pull requests opened from forks will be closed without being reviewed or merged.

You can still help improve the Input System:

* **Report bugs** through the Unity Bug Reporter, as described in [Reporting bugs](https://unity3d.com/unity/qa/bug-reporting). Please don't file issues in this repository.
* **Share feedback, questions, and feature requests** on [Unity Discussions](https://discussions.unity.com/tag/input-system/159343).

You remain free to fork the repository and change it for your own use, subject to the terms of the [license](LICENSE.md).

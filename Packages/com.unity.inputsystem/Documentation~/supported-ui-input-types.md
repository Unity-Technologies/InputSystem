# Supported input types in the UI Input Module

The UI Input Module supports three types of input Action: pointer, navigation, and tracked. For each input type, the UI Input Module sources and combines input from a specific set of Actions.

|**Topic**|**Description**|
|--------|-----------|
|[Pointer input UI support](supported-ui-input-types-pointer.md)| Configure pointer-type Actions, such as clicking, tapping, and scrolling.|
|[Navigation input UI support](supported-ui-input-types-navigation.md)| Configure navigation-type Actions, such as the `move` Action.|
|[Tracked input UI support](supported-ui-input-types-tracked.md)|Configure input from tracked devices, such as XR controllers and HMDs.|

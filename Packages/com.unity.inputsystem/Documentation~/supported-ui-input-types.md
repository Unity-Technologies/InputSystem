# Supported input types in the UI Input Module

Configure the three input categories the UI Input Module reads from your UI action map.

The module combines pointer, navigation, and tracked-device actions into Event System input. Use the topics below to wire clicks and scrolling, keyboard or gamepad navigation, and XR ray selection.

| **Topic** | **Description** |
| :--- | :--- |
| **[Pointer input UI support](supported-ui-input-types-pointer.md)** | Wire point, click, and scroll actions for mouse, touch, and pen UI interaction. |
| **[Navigation input UI support](supported-ui-input-types-navigation.md)** | Wire move, submit, and cancel actions for keyboard and gamepad UI selection. |
| **[Tracked input UI support](supported-ui-input-types-tracked.md)** | Wire tracked device position and orientation for XR UI raycasting with `TrackedDeviceRaycaster`. |
